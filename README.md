# 产品项目部工具优化平台（纯静态版）

这是一个可直接部署到 Netlify 的纯前端网站。无服务器、无云数据库、无登录，也不会控制本机钉钉。项目数据使用 IndexedDB 保存在当前浏览器，Excel/CSV 全程在浏览器本地解析。

> 本工具数据保存在当前浏览器，不会自动同步到其他电脑。换设备或清理浏览器数据前，请先在“本地数据”页面导出 JSON 备份。

## 本地运行与构建

```bash
npm install
npm run dev
npm test
npm run build
```

构建完成后生成 `dist`，它就是可部署的完整静态网站。项目包含 `public/_redirects`，构建后会复制到 `dist/_redirects`，用于 Netlify SPA 路由回退。

## 功能

- 首页监管台：跟进、风险、临期、日期待核对、筛选和 Excel/CSV 导出。
- 项目：Excel/CSV 导入、人工新增/编辑、软删除与恢复。
- 本地数据：IndexedDB 持久化、JSON 导出/导入、清空、虚构示例数据。
- 状态规则：实际日期为空不判断延期；前置节点晚完成仅提示风险；最终延期以验收为准；已验收项目退出日常跟进。
- 项目状态确认：按项目经理分组生成、保存、复制和导出提醒文案。
- 周报：只选择个人 Excel，并生成项目交付、质量控制、售后服务三个汇总文件。

## Excel 导入

支持 `.xlsx`、`.xls`、`.csv`。Excel 文件必须包含名为 `所有项目进度计划情况` 的工作表；CSV 没有工作表概念，会直接读取文件内容。找不到指定 Excel 工作表时会明确停止并提示。日期无法识别时标记为“日期待核对”，不参与延期判断。

## 隐私与限制

- 源码只包含虚构示例数据，不包含真实项目、真实 Excel、JSON 备份或钉钉信息。
- 静态网页无法自动打开、搜索、填写或发送钉钉消息。
- 浏览器合并会尽量保留常见 Excel 格式；图片、宏和特殊格式可能无法完整保留，复杂文件建议使用 Windows 桌面版合成。
