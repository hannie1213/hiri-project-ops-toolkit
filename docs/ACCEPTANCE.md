# 验收清单

- `npm test`：验证实际为空不算延期、前置节点风险、验收结果、已验收退出跟进、临期窗口、状态确认和多人经理分隔符。
- `npm run typecheck`：验证 TypeScript 类型。
- `npm run build`：生成可直接部署的 `dist`。
- Excel 导入：严格识别 `所有项目进度计划情况`；支持 xlsx/xls/csv；本地解析。
- 浏览器存储：IndexedDB 持久化；显示项目数与最后保存时间；JSON 备份、恢复、清空和虚构示例数据。
- 周报：不在线填写；按文件名识别固定名单；重复或无法识别时停止；生成三个文件且成员工作表以姓名命名。
- 钉钉：只生成、编辑、复制和导出文案，不显示“已发送”。
